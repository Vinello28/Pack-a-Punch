L¿ AUTOMATION PACKAGE  consentirà di trasformare le attività che richiedono tempo come creare  controllare  convertire  stampare e archiviare tutti i tipi di documenti digitali in un flusso di lavoro automatizzato.  SWITCH scaricherà automaticamente i lavori dal nostro server FTP  leggerà anche le e-mail  estrarrà gli allegati e sposterà automaticamente questi file nel flusso  monitorerà qualsiasi struttura di cartelle nella rete locale e ricorderà la loro posizione originale. I files verranno ordinati automaticamente in base alla loro tipologia e filtrati attraverso il Software PIT STOP SERVER che è un'applicazione hot folder autonoma che controlla e corregge i file PDF. Ciò  ridurrà il rischio di errori umani garantendo alta qualità su ogni commessa nonché libererà i nostri operatori dal  preflight PDF e la correzione degli errori comuni. Il Software CONNECT  ALL  consentirà invece di estendere l'automazione al desktop dei clienti. Nello specifico eseguirà nel loro computer le diverse attività che attualmente sono a carico dei nostri clienti per consegnarci i loro files: Creazione dei file PDF pronti per la stampa  Verifica e correzione degli errori comuni  Caricamento dei file di lavoro nel nostro server FTP o Email  Comunicazione delle relative specifiche tecniche.
