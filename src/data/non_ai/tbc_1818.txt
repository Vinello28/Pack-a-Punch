SU CRM WEB PREESISTENTE DELL'AZIENDA  E' STATO RICHIESTO LO SVILUPPO DI UN SISTEMA DI API CHE PERMETTA L'INTERFACCIAMENTO DEL CRM CON SOFTWARE DI TERZI. TRAMITE API E' INFATTI POSSIBILE  PER LE APPLICAZIONI AUTORIZZATE  ACCEDERE ALLE INFORMAZIONI MEMORIZZATE SUL GESTIONALE  PERMETTENDO AL CONTEMPO IL CARICAMENTO  LA MODIFICA E L'ELIMINAZIONE DELLE INFORMAZIONI. IL SISTEMA DI API E' STATO PENSATO PER L'INTEGRAZIONE CON DELLE APPLICAZIONI MOBILI NATIVE  PERMETTENDO ALLO STESSO TEMPO L'AUTOMATIZZAZIONE DEI FLUSSI DI LAVORO.
