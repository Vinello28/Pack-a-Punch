Il progetto prevede l'installazione di un nuovo server con Hypervisor Microsoft Hyper-V in affiancamento a quelli gi presenti per la gestione dei server virtuali necessari all'attivit della societ (database posta elettronica file storage...) e a garanzia di continuit operativa in caso di guasti (i server saranno replicati ed interscambiabili) oltre che l'installazione di uno storage NAS per l'archiviazione. Inoltre prevista la configurazione di un nuovo sistema di backup basato su Veeam Backup & Replication per la sicurezza dei dati. Il nuovo sistema studiato anche per la fornitura di nuovi servizi esterni ai clienti quali accessi online ad aree personali o creazione di archivi ad uso interno dello staff
