Il Piano Attuativo prevede tecnologie servizi e formazione per digitalizzare il processo produttivo attraverso tecnologie basate su analisi dati intelligenza artificiale IoT ecc. Nel dettaglio include: - server funzionale alla realizzazione del piano attuativo - software Vedo - formazione software Vedo - hardware Venus - software Venus - formazione hardware e software Venus - Vedo: si occupa dell archiviazione di immagini di vario tipo e provenienza. Nel caso di Fermo Fossati verr inserito/digitalizzato tutto l archivio storico dei disegni per tessuti dell azienda. Si tratta di un attivit di grande portata. Nel modulo vengono create dall utente le categorie ed i criteri di catalogazione. Ad ogni immagine archiviata vengono attribuite dall utente le categorie di appartenenza. Sono possibili strumenti di ricerca delle immagini catalogate secondo criteri modificabili dall utente. L archivio consultabile via browser da qualsiasi dispositivo. La visualizzazione delle immagini pu essere limitata in funzione dell utente di accesso. Vedo rappresenta uno strumento fondamentale per garantire la gestione in sicurezza velocit e facilit di tutti i file necessari per il processo di produzione tessile.
