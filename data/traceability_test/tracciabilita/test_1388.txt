IL PROGETTO CHE VERRÀ REALIZZATO SI CONCENTRERÀ SULL’IMPLEMENTAZIONE DI SISTEMI DI INTEGRAZIONE E DI SVILUPPO DIGITALE  CON PARTICOLARE FOCUS SULLA GESTIONE DELLA FLOTTA DI CAMION. L’OBIETTIVO È PROGETTARE E SVILUPPARE UN SOFTWARE AD HOC  SPECIFICAMENTE STUDIATO PER LE ESIGENZE AZIENDALI. LA CONSULENZA VERTERÀ DUNQUE SULLA RICERCA DELLA MIGLIORE SOLUZIONE PER OTTENERE UN’AUTOMATIZZAZIONE E SEMPLIFICAZIONE DEI PROCESSI CHIAVE LEGATI ALLA GESTIONE DELLA FLOTTA  PER MIGLIORARE L’EFFICIENZA OPERATIVA  GRAZIE AD UN SISTEMA DI TRACCIABILITÀ E MONITORAGGIO DEI CAMION. L’OBIETTIVO SARÀ LA CREAZIONE DI UN SISTEMA SOFTWARE SU MISURA  ALTAMENTE SCALABILE E PERSONALIZZABILE.   IL PROGETTO DI CONSULENZA SPECIALISTICA SFRUTTERÀ  PER LA PROGETTAZIONE DEL SOFTWARE  POTENTI TECNOLOGIE  QUALI IL FRAMEWORK DI SVILUPPO .NET PER LA CREAZIONE DELL’APPLICATIVO  SQL PER LA GESTIONE DEI DATABASE E LE REST API PER L’INTEGRAZIONE DEL SOFTWARE CHE VERRÀ CREATO CON LE ALTRE APPLICAZIONI UTILIZZATE DALL’IMPRESA. IL PROGETTO PREVEDE UNA FASE DI COLLAUDO  ATTRAVERSO TEST CASE  PER VERIFICARE IL CORRETTO ED EFFICIENTE FUNZIONAMENTO DI TUTTE LE FUNZIONALITÀ CHIAVE DEL SISTEMA  AFFINCHÉ LA CONSULENZA  NELLA SUA FASE CONCLUSIVA  SIA VOLTA ALLA RISOLUZIONE DI EVENTUALI PROBLEMI.
